# Umbra01: анимированный логотип

Вертикальное видео 9:16 для TikTok: 1080×1920, 60 fps, фиолетовый неон.
«Umbra» прорисовывается кистью штрих за штрихом, после этого влетает «01».

## Файлы в `out/`
| Файл | Для чего |
|---|---|
| `umbra01_intro_9x16.mp4` | **Начало ролика**, 4.2 с. Заканчивается глитчем и «выключением ТВ», поэтому сразу можно склеивать с видео |
| `umbra01_outro_9x16.mp4` | **Конец ролика**, 6 с. Логотип держится и плавно гаснет |
| `*_nosound.mp4` | Те же версии без звука |
| `sfx_intro.wav`, `sfx_outro.wav` | Звук отдельными файлами, если хотите сделать его тише или подложить свой трек |

## Таймлайн
| Время | Что происходит |
|---|---|
| 0.0–0.5 с | Из темноты проявляются дым, лучи света и частицы |
| 0.2–0.7 с | Мазок фиолетовой краски на фоне |
| 0.5–1.9 с | Кисть пишет «Umbra» (настоящий порядок штрихов), за ней летят искры, ниже стекают капли |
| 1.9–2.0 с | «01» влетает с удара: вспышка, ударная волна, брызги краски, тряска |
| 2.4–2.9 с | По логотипу пробегает блик |
| 3.2 с | Неон коротко мигает |
| 3.6–4.2 с | Только intro: глитч и схлопывание в линию |

## Как устроено
- `tools/prep.py` рендерит слово шрифтом Mr Dafoe и строит его скелет.
  Для каждого пикселя считается момент, когда кисть до него доходит (`data/timemap.png`).
- `logo.js` рисует кадр как функцию времени: фон, мазок, неоновое свечение, перо, «01», эффекты.
- `tools/sfx.py` синтезирует звук под таймлайн: эмбиент-подложка, шорох кисти, удар, звон, глитч.
- `render.mjs` рендерит кадры через headless Chromium и собирает видео в ffmpeg.

```bash
python3 tools/prep.py Umbra fonts/MrDafoe.ttf 330          # пересобрать time map (если поменять текст/шрифт)
python3 tools/sfx.py intro out/sfx_intro.wav
node render.mjs --video out/umbra01_intro_9x16.mp4 --v intro --audio out/sfx_intro.wav
node render.mjs --stills 1.2,2.05 --v intro --out stills/   # отдельные кадры
```
Шрифты Mr Dafoe и Orbitron распространяются по лицензии SIL Open Font License.
