# Аниме-боёвка: аниматик-референс для SFM

Референс-ролик длиной 13 секунд (312 кадров, 24 fps). По нему удобно собирать сцену в Source Filmmaker.
Сцена построена в настоящем 3D, поэтому позиции, высоту, FOV и крен камеры можно переносить напрямую.

## Файлы в `out/`
| Файл | Что это |
|---|---|
| `animatic_annotated.mp4` | Основной референс. На кадре: номер кадра, шот, ключи, параметры камеры, вид сверху, таймлайн |
| `animatic_annotated_x0.25.mp4` | То же самое в 4 раза медленнее, удобно разбирать каждый кадр |
| `animatic_clean.mp4` | Чистая версия без подписей, чтобы оценить общее ощущение |
| `frames/shotNN_*.jpg` | Раскадровка каждого шота: все уникальные кадры, через один (персонаж анимирован «на двойках») |
| `shotlist.md` | Таблица ключей и камеры по каждому шоту |

## Как читать манекен
- **Оранжевый** — правая рука и нога (рука с мечом). **Синий** — левая сторона.
- Чёрный «визор» на голове показывает, куда смотрит голова.
- Красный шарф — вторичное движение: он повторяет путь шеи с запаздыванием.
- Зелёная точка «поза обновилась» горит на чётных кадрах: персонаж меняет позу только на них, а камера движется каждый кадр.

## Перенос в SFM
1. В настройках сессии поставьте **24 fps**. Номера кадров в аниматике совпадут с SFM.
2. Повесьте риг на модель: ПКМ по набору анимации → Rig → `rig_biped_simple`.
3. Ставьте ключи **только на кадрах из таблицы** (`shotlist.md`, ромбики на таймлайне).
   - «держать, потом скачок» — ступенчатая (Step) интерполяция в Graph Editor.
   - Переходы длиной 2–4 кадра — ease out: быстро в начале, мягко в конце.
4. **Двойки.** Когда анимация готова, переведите ключи персонажа в Step и проставьте их через кадр.
   Камеру оставьте на сплайне, она должна идти плавно.
5. **Камера.** FOV, крен и высота подписаны на каждом кадре. Вид сверху показывает, где стоит камера относительно героя.
   - Облёт (шот 6): камеру прикрепите к вспомогательному объекту (dag) в центре героя и вращайте его.
   - Тряску ставьте отдельным слоем на саму камеру.
6. **SMEAR / IMPACT.** Smear-кадр — это одна промежуточная поза; растяжку оружия можно сделать масштабом кости.
   Impact-кадры (белый/чёрный силуэт, радиальные линии), вспышки, линии скорости и шлейфы проще добавить на монтаже (AE/DaVinci).

## Шоты
1. Затишье — наезд на лицо, голова рывком вверх
2. Замах — нижний ракурс, держать позу с дрожью
3. Рывок — whip pan, исчезновение со шлейфом
4. Перемещение рывками — слежение сбоку с отставанием
5. Удар в камеру — FOV 95–105, smear, impact
6. Заморозка и облёт 180°
7. Комбо 1 — горизонтальный удар, голландский угол
8. Комбо 2 — апперкот, камера с пола
9. Комбо 3 — сальто на двойках
10. Приземление — удар об землю, волна, тряска
11. Финал — встаёт, отъезд, взрыв вдалеке

## Перерендер
```bash
node render.mjs --video out/animatic_annotated.mp4 --mode annotated   # или --mode clean
node render.mjs --stills 120,122 --mode annotated --out stills/       # отдельные кадры
node render.mjs --shotlist out/shotlist.md
```
Позы задаются в `animatic.js` в объекте `POSES`, тайминг — в `CH` (ключи персонажа) и `RT` (положение в мире), камера — в `SH[].cam`.
