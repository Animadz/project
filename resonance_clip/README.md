# «Резонанс последствий»: процедурный lyric-клип

Киберпанк-клип под трек (5:49, ~143.5 BPM). Вся графика рисуется кодом на Canvas.
Тайминги текста взяты из субтитров внутри m4a, ритм — из анализа аудио (доли, бочка, громкость).

## Форматы
- `out/rezonans_posledstviy_16x9.mp4`: 1920×1080, для YouTube.
- `out/rezonans_posledstviy_9x16.mp4`: 1080×1920, для TikTok, Shorts и Reels.

Видео не хранятся в git: они больше лимита GitHub.

## Стили текста под типы вокала
| Вокал | Как выглядит |
|---|---|
| Шёпот (интро) | Строка «расшифровывается» из случайных символов, мерцает |
| Женский вокал | Расшифровка + подчёркивание, бело-красный / бело-голубой |
| Мужской autotune | Терминал: печать по буквам с курсором, лог предыдущих строк |
| Системный голос | Окна-алерты CERBERUS с предупреждающими полосами, мигание |
| Читка / рэп | Слова влетают по одному, крик красным, огромное «эхо» слова на фоне |
| Хоры, «РЕ-ЗО-НАНС» | Гигантский удар слово за словом / слог за слогом |
| Припевы | Крупная строка, капс-слова красным, гигантское эхо |
| Call & response | Вопрос шифром, ответ огромным ударом |
| Брейкдаун | Слова в случайных местах, отсчёт «Три, Два, Один» на весь экран, инверсия на «LOSE CONTROL» |
| Бридж | Тихий текст без глитчей, рассвет над руинами |

Поверх всего HUD: координаты, сектор, таймкод, шкала RESONANCE (громкость), спектр, hex-лог.
Глитчи привязаны к бочке:
- на картинку и HUD: срезы, блоки, пикселизация, VHS-полоса;
- на всё: RGB-сдвиг;
- на крупных моментах: вспышки, инверсия.

## Рендер
```bash
node render.mjs --stills 64.5,120 --ar 16x9 --out stills/
node render.mjs --audio track.m4a --out out/clip_16x9.mp4 --ar 16x9 --workers 4 --crf 20
node render.mjs --audio track.m4a --out out/clip_9x16.mp4 --ar 9x16 --workers 4 --crf 20
```
Данные пересобираются через `tools/analyze.py`, `tools/parse_srt.py` и `tools/build_data.py`, как в `clip/README.md`.
